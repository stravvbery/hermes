# 🐓 Петухъ.ру — Первый Голос Земли

Одностраничный сайт-памфлет о петухах, петушочках и кочетах. Vanilla HTML/CSS/JS, без сборки, без зависимостей.

## Запуск

```bash
cd petukhi
python3 -m http.server 8989
# открой http://localhost:8989
```

Или просто открой `index.html` в браузере (Web Audio требует HTTP — иначе кукарек не сработает в Chrome).

## Что внутри

- **Hero** — портрет петуха (сгенерирован Gemini), кнопка `КУКАРЕКНУТЬ` синтезирует крик в Web Audio API + тряска экрана.
- **Манифест** — поэтическое введение про монарха курятника.
- **Анатомия** — интерактивная SVG-схема с 8 кликабельными пинами (гребень, серёжки, клюв, грива, косицы, поясница, шпоры, плюсна).
- **Породы** — карточки 8 пород (Брама, Леггорн, Орловский, Павловская, Кохинхин, Виандот, Бентамка, Австралорп) с реальными фото.
- **Факты** — 8 неочевидных фактов о кочетах (циркадный ритм, 130 дБ, УФ-зрение и т.д.).
- **Кукарекомер** — счётчик кликов с уровнями (Цыплёнок → Бог рассвета), рекорд и серия в секунду в `localStorage`.
- **Тест «Какой ты петух?»** — 5 вопросов, выдаёт породу.
- **Зал славы** — Galo de Barcelos, Шантеклер, Foghorn Leghorn, Mike the Headless и др.
- **Пасхалка** — Konami code (↑↑↓↓←→←→BA) запускает дождь петухов.

## Стек

- HTML + CSS (vanilla, ~24 KB)
- JavaScript (vanilla, ~23 KB)
- Web Audio API для синтеза кукарека (4 ноты + шумовой бёрст)
- Intersection Observer для появления секций
- LocalStorage для счётчика
- Google Fonts: Unbounded (display), Manrope (body), Marck Script (акцент)
